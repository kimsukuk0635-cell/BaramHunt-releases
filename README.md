# 바람태초 배포

[최신 실행기 다운로드](https://github.com/kimsukuk0635-cell/BaramHunt-releases/releases/latest/download/BaramHunt.exe)

1. 실행 중인 기존 바람태초 프로그램을 종료합니다.
2. 위 링크의 BaramHunt.exe로 기존 실행기를 한 번 교체합니다.
3. 이후에는 같은 실행기를 켜면 새 버전을 확인하여 다운로드하고 적용합니다.

기존 PC의 설정과 사냥 기록은 유지됩니다. 시작할 때 업데이트 확인 상태와 다운로드 진행률이 표시됩니다.

[버전별 변경 사항](https://github.com/kimsukuk0635-cell/BaramHunt-releases/releases)

업데이트 ZIP과 latest.txt는 실행기가 사용하는 파일입니다. 일반 사용자는 EXE만 받으면 됩니다.
